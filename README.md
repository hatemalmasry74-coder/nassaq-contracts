# nassaq-contracts
Nassaq Contracts Management Platform — منصة نسق لإدارة العقود والتشغيل

## آخر التحديثات

### 🔒 الحذف لمدير الشركة فقط
- كل عمليات الحذف (زيارات، عقود، عملاء، مشاريع، مستخدمون، مستندات، ...) أصبحت متاحة لدور **مدير الشركة** فقط، وأزرار الحذف مخفية لباقي الأدوار.
- كل سجل يُحذف تُحفظ نسخة كاملة منه في **🗑️ سلة المحذوفات** ويمكن استرجاعه.

### 📜 تقارير التعديل والحذف
- كل إضافة / تعديل / حذف / استرجاع تُسجَّل مع اسم المستخدم والوقت والحقول التي تغيّرت (قبل ← بعد).
- التعديل يمكن **التراجع** عنه، والحذف يمكن **استرجاعه** — من صفحة "تقارير التعديل والحذف" (للأدمن فقط)، مع فلاتر وطباعة وتصدير Excel.

### 🚶 الزيارات
- **زيارة استكشافية**: لبراند غير مسجّل بعد — يُكتب اسم البراند داخل الزيارة، ويمكن لاحقاً "تسجيل البراند" بضغطة وربط كل زياراته السابقة به.
- **أكثر من مشرف في الزيارة**: مشرف رئيسي + مشرفون مشاركون، والزيارة تُحتسب لكل مشرف (في حساب الزيارات، التقارير، ملف العضو، والفلاتر).

### 📦 أرشفة المشاريع
- المشاريع المكتملة/الملغاة تُؤرشف (فردياً أو دفعة واحدة) وتنتقل لتبويب "الأرشيف" ويمكن إعادتها.

### 🛡️ إصلاحات أمنية
- إلغاء منح صلاحية "مدير" تلقائياً لأي حساب بدون سجل صلاحيات.
- التسجيل الذاتي ينشئ حساباً **بانتظار التفعيل** (بدون أي صلاحية) حتى يحدد الأدمن دوره.
- إيقاف حفظ كلمة المرور نصاً صريحاً في المتصفح، وإنشاء المستخدمين لم يعد يتطلب ذلك.
- حماية من حقن الأكواد (XSS) في النصوص المحفوظة، ومن حقن الصيغ في ملفات Excel المصدّرة.
- تنظيف النسخة المحلية من البيانات عند تسجيل الخروج.

## ⚠️ خطوة مهمة: تفعيل قواعد الأمان في Firebase
فحوصات الصلاحيات داخل الصفحة وحدها لا تكفي — يجب نشر ملف `firestore.rules` لتُطبَّق على الخادم:

1. **قبل النشر** تأكد أن حسابك موجود في مجموعة `app_users` (Firestore → app_users → مستند بمعرّف حسابك) وأن الحقل `role` = `admin_company`.
2. افتح [Firebase Console](https://console.firebase.google.com) → مشروع **nassaq-crm** → Firestore Database → **Rules**.
3. انسخ محتوى ملف `firestore.rules` والصقه مكان القواعد الحالية ثم اضغط **Publish**.
4. يُفضَّل أيضاً من Authentication → Settings تعطيل إنشاء الحسابات الذاتي إن لم تكن بحاجة له.
